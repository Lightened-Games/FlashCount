Original meshes generated for Flash to Bang (no third-party input): tank, church tower, haystack, ridge post, farmhouse,
stone bridge and tree cards. Built at runtime from code by Source/FlashtoBang/World/FTBMeshLib.cpp, FTBWorldBuilder.cpp
and FTBTank.cpp; these glTF 2.0 files are written by the same builders (game launched with -FTBExportMeshes).
Textures applied in game: the Poly Haven CC0 sets in Textures/PolyHaven and our own Textures/Generated.
